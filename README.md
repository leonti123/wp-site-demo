# Сайт на WordPress «Мастер Дом» (демо)

Демо-проект для портфолио: сайт услуг на WordPress, собранный на блоках Gutenberg
(тема Twenty Twenty-Four). Компания вымышленная.

**Открыть живое демо:** https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/leonti123/wp-site-demo/main/blueprint.json

Сайт запускается прямо в браузере через официальный WordPress Playground, ничего устанавливать не нужно.
Админка: добавьте `&login=yes` к ссылке демо (логин `admin`, пароль `password`, это локальное окружение в вашем браузере).

## Что сделано
- главная страница из блоков: обложка с призывом, услуги и цены, этапы работы, отзывы, контакты
- адаптивная вёрстка для телефона
- свои стили через mu-plugin (`demo-style.php`): акцентный цвет, карточки
- страницы «Услуги», «О нас», «Контакты», статическая главная, русская локализация

## Файлы
- `blueprint.json` — сборка сайта для WordPress Playground
- `setup.php` — создание страниц и настройка главной
- `demo-style.php` — стили сайта
